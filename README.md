# 🎮 Tic-Tac-Toe Game Using Python

## 📌 Project Description

Tic-Tac-Toe is a simple two-player game developed using Python.
The game is played on a 3 × 3 grid where two players take turns
marking spaces with X and O.

The first player to get three matching symbols in a horizontal,
vertical, or diagonal line wins the game.

If all positions are filled and neither player wins, the game
ends in a draw.

This project is designed for beginners to practice Python
programming concepts.

## 🎯 Objectives

- Develop a two-player Tic-Tac-Toe game using Python.
- Practice Python functions and loops.
- Understand lists and conditional statements.
- Implement input validation.
- Detect winning combinations.
- Identify draw conditions.
